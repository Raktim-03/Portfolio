# Information & Documents Needed to Personalize Your Portfolio

Please send the following so I can complete your portfolio:

## 1) Personal & Branding
- Full name
- Professional title/tagline (e.g., "Full-Stack Developer")
- Short bio (3–6 lines)
- Location (optional)
- Profile photo (optional)
- Preferred color palette or brand style (minimal, dark, neon, etc.)

## 2) Contact & Social Links
- Email
- Phone (optional)
- LinkedIn URL
- GitHub URL
- Portfolio domain (if any)
- Resume/CV file (PDF)

## 3) Projects (Most Important)
For each project:
- Project name
- Problem statement
- Your role
- Tech stack
- Key features (3–6 bullets)
- Screenshots/demo images
- Live URL (if available)
- GitHub repo URL
- Impact/results (metrics if possible)

## 4) Skills
- Frontend skills
- Backend skills
- Databases
- DevOps / Cloud
- Tools (Git, Figma, etc.)

## 5) Experience (Optional but recommended)
For each role:
- Company name
- Role
- Start date – End date
- Responsibilities (bullets)
- Achievements

## 6) Education & Certifications
- Degree / Institution / Year
- Certifications with issuer + date

## 7) Testimonials (Optional)
- Quote
- Author name + role

## 8) Additional Sections (Choose)
- Blog
- Case studies
- Open source
- Awards
- Speaking / Workshops

## 9) Functional Preferences
- Contact form should send to email? If yes, provide destination email.
- Do you want a dark/light mode toggle?
- Should we include animations and parallax effects?
- Should admin editing be added for project updates?

## 10) Documents / Assets
Please upload/share:
- Resume (PDF)
- Project screenshots
- Logos/icons
- Any writing samples or case studies
